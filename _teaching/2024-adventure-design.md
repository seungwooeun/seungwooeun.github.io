Teaching assistant for **Adventure Design** (course code CB1501008), a first-year, project-based undergraduate course in the Computer Science and Engineering program at Pusan National University, taught by Prof. Myungho Lee.

Course overview
======
A hands-on introduction to IoT hardware programming and system interfacing, with the kind of hardware used across embedded applications, the Internet of Things, and robotics. Students learn the operating principles of microcontrollers and how to use them, covering interrupts, port control, memory management, I/O programming, and communication with external devices (serial, wireless, PPI), all through hands-on practice with Arduino.

Topics
======
* Arduino basics and the Arduino IDE
* Digital input/output and serial/parallel circuits
* Analog input/output
* Speaker and sensor control
* 7-segment displays and text LCDs
* Motor control
* Serial communication and sensor applications
* Team project: designing and building an Arduino-based system

**Tools:** Arduino (Arduino IDE)  
**Textbook:** *따라 하면서 배우는 아두이노*, 허경용, 한빛아카데미 (2016).

As a TA, I ran the weekly Arduino labs and assignments and helped students debug their hardware and code through the final team project.
